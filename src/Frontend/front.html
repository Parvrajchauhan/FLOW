FLOW

Multi Modal Agentic AI built with LangGraph, FastAPI.

What is FLOW?

FLOW is a deployed agentic application that accepts multiple input types simultaneously Text, Images, PDFs, and Audio extracts their content, understands your goal, and autonomously performs the correct task. Complex, multistep queries are handled in a single request with no stepbystep prompting required.

Supported Inputs

  • Text plain or structured queries
  • Image (JPG/PNG) OCR extraction with confidence score
  • PDF text parsing + OCR fallback for scanned docs
  • Audio (MP3/WAV/M4A) speech-to-text + cleanup
  • Multiple files at once cross-input reasoning supported

What the Agent Can Do

  • Extract & transcribe content from any input type
  • Fetch YouTube transcripts from URLs found inside PDFs or images
  • Summarize: 1-line summary, 3 bullets, 5-sentence summary
  • Sentiment analysis: label, confidence & justification
  • Code explanation: logic, bugs & time complexity
  • Cross-input reasoning: compare audio vs PDF, combine sources
  • Ask a clarifying question if the goal is ambiguous never guesses

Agent Architecture

Planner → Router → QA / Tool / Code → Formatter → Streaming Output

Bonus Features

  • Token-by-token streaming output in chat UI
  • Real-time plan trace see every tool invoked and in what order
  • Extracted content panel alongside final agent response

Conversation Memory Not Available

FLOW currently does not retain conversational history between messages. Each request is processed independently, so the agent may not remember information shared earlier in the conversation.
